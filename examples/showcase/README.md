# The showcase set

Six motifs and eleven pattern documents, drawn for this repository and
rendered by it. They are what [patternated.com](https://patternated.com)
shows, and they exist so that a stranger who clones this can produce every
picture on that site.

That last part is why they are here rather than only there. The other example
set, `../generated-motifs/`, is generated artwork used as a validation input,
and its PNGs are gitignored: binary assets accumulate in history forever. The
consequence is that a clean clone could render almost none of it. These are
SVG, a few kilobytes each, and tracked.

```bash
cargo run -p pattern-cli -- render examples/showcase/ditsy.json --out ditsy.png --cols 3
```

## Regenerating

```bash
python3 examples/showcase/make-showcase.py
```

It writes into its own directory and needs nothing installed. Everything here
is generated by it, the drawings included, and **the files should not be
edited by hand**, because several of them make a claim about each other that
an edit would quietly break:

- `grid-block`, `grid-brick` and `grid-half-drop` are the same document apart
  from **one field**. Block to brick is `row_offset: 0.5`; block to half-drop
  is `col_offset: 0.5`. Nothing else differs, and a diff of any two of them
  should print one line.
- `colourway-day` and `colourway-night` differ in **`pattern.palette` and
  nothing else**, including the `design_palette` that is redundant in the day
  version and carried anyway so the pair is exactly comparable.

Break either and the pictures still render. The captions on the website are
what stop being true.

## The motifs

Flat vector, no outline, three or four colours each, all from one palette of
ten slots. Written as a style brief at the top of `make-showcase.py` and then
drawn against it, which is the same discipline `../generated-motifs/STYLE.md`
applies to generated artwork and the reason separate drawings read as one
hand.

| | |
| --- | --- |
| `sprig` | A stem of paired leaves. The lightest, so a dense scatter of it still reads open. |
| `bloom` | Eight petals and a centre. The anchor: round, symmetrical, high contrast. |
| `seedhead` | Sixteen spokes with tipped dots. The only linear mass, and the one that gives a scatter somewhere to breathe. |
| `leaf` | One broad leaf. The largest single shape, for statement repeats. |
| `berry` | Three berries on forked stems. Holds up smallest. |
| `bud` | The filler. Every strewn pattern needs something small enough to sit in the gaps, and shrinking a large motif to do that job pays for detail nobody can see. |

**Scale is a property of the document, not of the drawing.** The same `bud` is
a 38 mm shape in `damask.json` and a 23 mm one in `ditsy.json`. A drawing has
no natural size on cloth, so `natural_size_mm` is where that is decided and a
ditsy is made by using small motifs rather than by thinning a scatter of large
ones.

## The documents

| | |
| --- | --- |
| `night-strewn` | A half-drop scatter on a dark ground. The website's hero. |
| `grid-block`, `grid-brick`, `grid-half-drop` | One document, one field, three prints. |
| `colourway-day`, `colourway-night` | One drawing, two cloths. Motifs hold palette slots, never literal colours, so a colourway is a swap rather than a redraw. |
| `ground-tartan` | A `bands` ground with a symmetric sett and a full crossing table. |
| `ground-texture` | A `texture` ground: reaction-diffusion, grown rather than drawn. |
| `ground-ornament` | An `ornament` ground: interlocking scallops on a 56 mm cell. |
| `ditsy` | A small-scale strewn print, and the example the website's build command renders. |
| `damask` | A side-to-side mirror, with a third of the placements on the axis. |

## Two things worth knowing before editing a ground

**A check with no crossings is not a check.** Where a vertical band meets a
horizontal one the horizontal simply wins unless a `crossings` entry says
otherwise, so a sett with none reads as horizontal bars with the vertical
bands showing through the gaps. `ground-tartan` names every crossing: the two
ground colours resolve to opposite colours each way round, so they chequer,
and the fine overcheck threads stay on top of both.

**Sett colours need to differ in value, not only in hue.** The first attempt
used sage against forest. Both are mid greens, the chequer was invisible, and
the result read as green bars.
