# Contributing

**Bug reports and issues are very welcome. Pull requests are not accepted.**

That is not standoffishness, and it is worth explaining rather than leaving as
a closed door.

This engine is published under AGPL-3.0 while remaining usable inside
Captivated Ltd's own closed products. That works only because Captivated owns
the copyright outright: a copyright holder is not a licensee of its own work.
A merged contribution would put copyright in somebody else's hands, ownership
would stop being whole, and the arrangement would quietly stop holding.

The useful things you can do instead, in rough order of how much they help:

- **Report what broke, with the file that broke it.** The longest-standing
  weakness here is that very little artwork has been through the ingest
  pipeline that this project did not draw itself. A real SVG that fails, or a
  scan that mattes badly, is worth more than a patch.
- **Say what it got wrong on fabric.** Nothing is more useful and almost
  nobody can supply it.
- **Describe a feature and why**, especially if the reason is a constraint a
  printer imposed on you.

If contributions ever become valuable enough to be worth the administration, a
contributor licence agreement is the mechanism and this file will say so.
